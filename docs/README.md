# Trip Map documentation

| File | What it is |
| --- | --- |
| [DESIGN.md](DESIGN.md) | The app's design: goals, screens, map format, sharing, security, privacy, and the build plan. The source of truth for what the app does. |
| [icons/](icons/) | The app's icon set, as shown in the design (section 5.4). |

Changes to the design are made the same way as changes to the code: by pull request, merged only by the app's owner (DESIGN.md section 13).
