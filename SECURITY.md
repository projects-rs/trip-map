# Reporting a security problem

If you find a security problem in Trip Map, please report it privately, not in a public issue:

- On GitHub, open the repository's **Security** tab and choose **Report a vulnerability**.

Please describe what you found and how to reproduce it. The app owner will reply within 7 days, and will tell you when it is fixed.

How the app protects its users is described in [docs/DESIGN.md](docs/DESIGN.md), section 14.3.
