# Trip Map icon set

The icons used on the map's pins and in the legends (DESIGN.md section 5.4). The app loads them from this folder, and the design document shows the same files.

Each icon is a 44 × 44 SVG: a dark circle with a white symbol. `icons.json` lists every icon with its ID, name, the icon set version it was added in (`since`), and an example; its `iconSetVersion` is the version of the whole set (DESIGN.md section 12.4).
